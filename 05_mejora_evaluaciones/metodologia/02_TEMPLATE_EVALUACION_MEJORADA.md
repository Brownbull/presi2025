## ESTRUCTURA DE EVALUACIÓN POR CANDIDATO

Para cada candidato, seguir esta estructura:

### 1. NOMBRE DEL CANDIDATO

### 2. IDENTIFICACIÓN DE MEDIDAS RELEVANTES

**OBLIGATORIO:** Antes de evaluar, consultar la Tabla Maestra del candidato en:
`05_mejora_evaluaciones/analisis/tabla_maestra_[Nombre_Candidato].md`

**Listar medidas específicas relevantes para el perfil del evaluador:**
- Medida X: [Descripción exacta de la tabla maestra] [p.Y]
- Medida Z: [Descripción exacta de la tabla maestra] [p.W]

### 3. EVALUACIÓN PERSONAL

**Formato:** Primera persona, manteniendo la voz y experiencia del personaje.

**Estructura sugerida:**
```
[Reacción personal a las medidas identificadas]

**Medidas que valoro positivamente:**
- Medida X [p.Y]: [Por qué es importante para mí]
- Medida Z [p.W]: [Cómo me afecta directamente]

**Medidas que me preocupan:**
- Medida A [p.B]: [Por qué no me convence]
- Medida C [p.D]: [Qué problemas le veo]

**Ausencias notables:**
No encuentro medidas sobre [tema específico]. Consulté la Tabla Maestra y verifiqué
que efectivamente no hay propuestas sobre:
- [Tema ausente 1]
- [Tema ausente 2]

**Valoración final:**
[Síntesis personal considerando presencia, ausencia y calidad de medidas]
```

### 4. CALIFICACIÓN NUMÉRICA

**Calificación Personal:** X/10

**Criterios de calificación:**
- 9-10: Programa excepcional que aborda mis necesidades de manera integral y concreta
- 7-8: Programa sólido con propuestas relevantes, algunas ausencias menores
- 5-6: Programa con algunas propuestas útiles pero insuficientes
- 3-4: Programa con pocas medidas relevantes o muy genéricas
- 1-2: Programa que ignora mis necesidades o propone soluciones contraproducentes

### 5. DECISIÓN DE VOTO

**¿Votaría por este candidato?** [Sí / Tal vez / No] - [Razón principal]

## REGLAS DE CONSISTENCIA FACTUAL

### ✅ CORRECTO:

1. **Citar medidas existentes:**
   ```
   "Propone X (Medida 123, p.45), lo cual me parece insuficiente porque..."
   ```

2. **Reconocer ausencias verificadas:**
   ```
   "No encuentro medidas sobre Y. Verifiqué en la Tabla Maestra (584 medidas)
   y efectivamente no hay propuestas específicas sobre este tema."
   ```

3. **Diferenciar entre ausencia total y falta de detalle:**
   ```
   "Menciona 'fortalecimiento de salud' (Medida 50, p.20) pero sin concretar
   cuántos profesionales, qué presupuesto o qué plazos."
   ```

4. **Valoraciones diferentes sobre la misma medida:**
   ```
   Doctor: "La telemedicina (Medida 100, p.30) puede ayudar pero no reemplaza
   la atención presencial en urgencias."

   Paciente rural: "La telemedicina (Medida 100, p.30) me cambiaría la vida,
   no tengo especialistas a 200 km."
   ```

### ❌ INCORRECTO:

1. **Inventar medidas:**
   ```
   "Propone X" → Sin verificar que X existe en la Tabla Maestra
   ```

2. **Negar medidas existentes:**
   ```
   "No menciona nada sobre Y" → Cuando la Medida 200 habla específicamente de Y
   ```

3. **Atribuir contenido no explícito:**
   ```
   "Su propuesta implica despedir funcionarios" → Cuando la medida dice
   "reestructuración administrativa" sin mencionar despidos
   ```

4. **Contradicciones entre evaluadores:**
   ```
   Evaluador A: "Tiene medida sobre Z"
   Evaluador B: "No tiene nada sobre Z"
   → Ambos deben consultar la MISMA Tabla Maestra y llegar al mismo hecho
   ```

## PROCESO DE VERIFICACIÓN

### Antes de publicar una evaluación:

1. ☐ Consulté la Tabla Maestra del candidato
2. ☐ Todas las medidas citadas tienen su número y página
3. ☐ Las ausencias fueron verificadas en la Tabla Maestra
4. ☐ No atribuí contenido que no está explícito en el programa
5. ☐ Mi valoración personal está claramente separada de los hechos
6. ☐ Usé la voz y experiencia del personaje de manera consistente

### Para verificación cruzada entre evaluadores:

1. ☐ Comparar qué medidas citan diferentes evaluadores sobre el mismo tema
2. ☐ Verificar que no haya contradicciones factuales
3. ☐ Asegurar que las diferencias son de valoración, no de hechos
4. ☐ Confirmar que las ausencias reportadas son consistentes

## EJEMPLO DE EVALUACIÓN MEJORADA

### Eduardo Artes

**Medidas relevantes identificadas (Tabla Maestra: 151 medidas totales):**
- Medida 89: "Grandes monopolios de salud serán socializados" [p.205]
- Medida 90: "Sistema único de salud estatal, gratuito, universal" [p.206]
- Medida 92: "Fin al negocio de las ISAPRES" [p.207]

**Evaluación personal:**

Leo estas propuestas y como médico en las trincheras necesito entender qué significa "socializar monopolios de salud" (Medida 89, p.205). ¿Las clínicas privadas donde trabajo para pagar mi deuda de $45 millones van a ser estatizadas? ¿Qué pasa con mi fuente complementaria de ingresos?

El "sistema único estatal" (Medida 90, p.206) suena a revolución, pero ¿cuándo? ¿Cómo? Ya escuché discursos similares. Necesito saber: ¿cuántos médicos más? ¿Qué presupuesto? ¿En qué plazo?

**Ausencias verificadas:**
Revisé las 151 medidas en la Tabla Maestra de Artes y NO encontré:
- Medidas sobre protección legal a funcionarios de salud contra agresiones
- Propuestas de condonación de deuda para profesionales de la salud
- Metas de contratación de especialistas con números específicos
- Incentivos para retención de profesionales (salarios, condiciones laborales)

Encuentro "aumento de presupuesto" mencionado en términos generales, pero sin cifras, plazos ni distribución específica.

**Valoración final:**
El discurso revolucionario no resuelve mis problemas concretos. Puedo coincidir ideológicamente con un sistema único estatal, pero necesito ver EL CÓMO y EL CUÁNDO, no solo EL QUÉ. Las ausencias en condiciones laborales y protección del personal son críticas.

**Calificación Personal:** 2/10

**¿Votaría por este candidato?** No - Pura ideología sin soluciones prácticas y plazos concretos para la crisis sanitaria que vivo todos los días.

Este template asegura:
1. ✅ Trazabilidad completa a las Tablas Maestras
2. ✅ Consistencia factual entre evaluadores
3. ✅ Separación clara entre hechos (medidas) y valoraciones (opiniones)
4. ✅ Verificación de ausencias para evitar afirmaciones incorrectas
5. ✅ Mantenimiento de la voz única de cada personaje
6. ✅ Posibilidad de auditar cada evaluación

**La regla de oro:** SIEMPRE consultar la Tabla Maestra antes de afirmar que una medida existe o no existe.
