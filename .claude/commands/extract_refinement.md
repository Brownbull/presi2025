# Presidentail Program Analysis System

## Step 1
Step 1: For a given candidate, analyze or create presidential refined program extract located at /03_extract_refinement/ directory. In case it does exists create it with name extract_{candidate}.txt in folder /03_extract_refinement/ using the candidate's correspongin text file located at 02_extract folder. 

## Step 2
Step 2: Reference the directory /claude/standards/ and find the file extract_refinement_standard.md, then based on that file, grade the outputs of Step 1 objectively against that standard, and give your response on a scale of 1 to 10

## Step 3
Step 3: For any presidential program extract that have a score less than 8 out of 10, you must refine and enhance them aiming to improve the score, and then repeat from Step 1
