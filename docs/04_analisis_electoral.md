## Gatillos de Voto/No Voto

### 🟢 **Movilizadores** (aumentan participación)
1. Candidato "outsider" creíble
2. Propuesta rupturista clara
3. Campaña emocional potente
4. Crisis pre-electoral
5. Polarización extrema

### 🔴 **Desmovilizadores** (reducen participación)
1. Todos candidatos "más de lo mismo"
2. Escándalo transversal
3. Propuestas poco creíbles
4. Campaña muy larga
5. Sensación de resultado cantado

## Perfiles de Candidatos Ideales

### 👤 **El Restaurador**
- Hombre 50-60 años
- Experiencia ejecutiva
- Sin militancia reciente
- Discurso orden y progreso
- **Apela a**: Clase media tradicional

### 👤 **La Renovadora**
- Mujer 35-45 años
- Profesional destacada
- Regiones
- Pragmática
- **Apela a**: Mujeres + jóvenes moderados

### 👤 **El Outsider**
- 40-50 años
- Empresario o académico
- Sin pasado político
- Antisistema moderado
- **Apela a**: Independientes hastiados

### 👤 **La Transformadora**
- Mujer 30-40 años
- Líder social
- Base territorial
- Discurso dignidad
- **Apela a**: Jóvenes + pobladores

## Temas Bomba que Pueden Cambiar Todo

### 💣 Potenciales Game Changers
1. **Mega portonazo/secuestro** → Vuelco a seguridad
2. **Colapso Isapre** → Salud prioridad 1
3. **Crisis migratoria norte** → Cierre fronteras
4. **Escándalo corrupción masivo** → Antisistema sube
5. **Crisis económica global** → Voto conservador
6. **Estallido 2.0** → Polarización extrema

## Errores Fatales a Evitar

### ☠️ **Suicidios Políticos**
1. Prometer nueva Constitución (divide)
2. Hablar de más impuestos (rechaza clase media)
3. Indulto a violentistas (pierde centro)
4. Negar problema migración (pierde norte)
5. Minimizar delincuencia (pierde todos)
6. Atacar FF.AA. (pierde conservadores)
7. Defender modelo actual (pierde jóvenes)

## Conclusiones Estratégicas

### Para Ganar Primera Vuelta
- **Necesario**: 35-40% (3 millones votos)
- **Base dura**: 25% mínimo
- **Capturar**: Independientes + desencantados
- **Mensaje**: Claro, simple, emocional

### Para Ganar Segunda Vuelta
- **Necesario**: 50% + 1 (3.8 millones)
- **Clave**: Sumar sin perder base
- **Centro**: Decisivo (1.5M votos)
- **Estrategia**: Moderar sin traicionar

### El Candidato Ganador Será Quien:
1. **Canalice** el hartazgo sin asustar
2. **Prometa** seguridad con dignidad
3. **Una** sin polarizar excesivamente
4. **Concrete** sin caer en populismo
5. **Represente** cambio con experiencia

- **Participación joven**: Si supera 45% gana progresismo
