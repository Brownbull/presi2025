# Presidentail Program Analysis System

## Step 1
Step 1: For a given candidate, analyze or create presidential program extract located at /02_extract/ directory. In case it does exists create it with name extract_{candidate}.txt in folder /02_extract/ using the candidate's correspongin text file located at 01_programas\ss_{latestest}\txt folder.

## Step 2
Step 2: Reference the directory /docs/standards/ and find the file plan_standard.md, then based on that file, grade the outputs of Step 1 objectively against that standard, and give your response on a scale of 1 to 10

## Step 3
Step 3: For any presidential program extract that have a score less than 8 out of 10, you must refine and enhance them aiming to improve the score, and then repeat from Step 1
